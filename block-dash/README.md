# Block Dash

Jogo de corrida e pulo no estilo dos "Block Dash" / Geometry Dash da Play Store, feito em HTML5 Canvas puro.
Não precisa instalar nada: é um único arquivo.

## Como jogar

- Abra `index.html` no navegador (celular ou PC), ou sirva a pasta: `npx serve block-dash`.
- Toque na tela, clique, ou aperte `Espaço` / `↑` para pular. Segure para pular sem parar.
- Almofada amarela: lança bem alto. Anel amarelo: toque quando o cubo passar por ele.
- `Esc` ou `P` pausa, `R` reinicia.

## O que tem

- 3 fases (Fácil, Normal, Difícil) e o modo Infinito, que acelera sem parar.
- Espinhos, blocos, escadas, almofadas de pulo e anéis.
- Música e efeitos sintetizados em tempo real (Web Audio).
- 7 cores de cubo, contador de tentativas, recorde salvo no aparelho.

`game.html` é a mesma página sem o cabeçalho HTML, usada para publicar como Artifact.
